## 🕐 About The Project

**Premium Wall Clock** is a modern real-time analog clock built from scratch using **HTML, CSS, and JavaScript**.

The project focuses on creating a clean, responsive and attractive clock interface without using frameworks or external libraries.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🕐 Analog Clock | Real-time moving clock hands |
| 🔢 Circular Numbers | Mathematically positioned numbers |
| ⏱️ Digital Time | Live digital time display |
| 📅 Date | Automatically updated date |
| 🎨 Premium UI | Dark, modern clock design |
| 📱 Responsive | Works across different screen sizes |
| ⚡ Lightweight | No frameworks required |

---

## 🛠️ Built With

**HTML5**  
Structure and clock interface.

**CSS3**  
Design, shadows, gradients, positioning and responsive layout.

**JavaScript**  
Real-time clock calculations, circular positioning and DOM manipulation.
